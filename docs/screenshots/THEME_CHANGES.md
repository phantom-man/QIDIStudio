## Screenshot Capture Procedure (when full build is available)

```powershell
# Build QIDIStudio with Dark Forge theme
Set-Location C:\QIDISrc\QIDIStudio\build
cmake --build . --target install --config Release -- /m:16

# Launch and capture
& "C:\QIDISrc\QIDIStudio\install_dir\QIDIStudio.exe" --screenshot-mode
# Creates: C:\QIDISrc\QIDIStudio\install_dir\screenshots\*.png
# Copy to: C:\Users\User\source\repos\QIDIStudio\docs\screenshots\
```

Alternatively, once an Extension Development Host is running:

```bash
cd C:\Users\User\source\repos\nexusslicer-viewer
# Press F5 in VS Code → installs extension in dev host → open any .stl file
# Use snipping tool or Win+Shift+S to capture the viewport
```
