Features

Everything a slicer needs.
Nothing it doesn't.

Built from the ground up as a VS Code extension. No separate app to switch to — your editor is the slicer.

WebGPU 3D Viewer
Physically-based rendering with real material shaders runs directly in the editor panel. Smooth, GPU-accelerated, and sharper than any standalone slicer available today.
Cloud Material Profiles
Hundreds of community-tuned filament profiles sync automatically on launch. eSUN, Polymaker, Bambu, and more — temperature, flow, and pressure advance all dialled in.
Precision Rotation Controls
Three-axis rotation panel with coarse, fine, and micrometer modes. Hold modifier keys for sub-degree precision. The kind of control product developers actually need.
Layer-by-Layer Preview
Scrub through every printed layer before you commit. Catch overhangs, check supports, verify infill pattern — before the first gram of filament is used.
AI-Assisted Settings
Ask Copilot Chat why a print failed, request parameter suggestions, or describe a surface defect — the answer is inline, in context, without leaving the editor.
STL, 3MF & OBJ Support
Open any major 3D format directly. Drag a file in, preview it, configure settings, slice it. Full multi-part 3MF support including embedded print profiles.
