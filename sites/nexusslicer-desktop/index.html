What We Fixed

QIDIStudio is shipped broken.
We’ve been through every line.

Six known defects in every public release. Here’s what NexusSlicer Desktop corrects out of the box.

✓ Fixed
Mode Switcher Restored
Simple, Advanced, and Developer mode buttons are fully unlocked and functional. Access every print parameter, not just the ones QIDI decided you should see.
All three buttons were commented out in the source. Users had no way to leave Simple mode.
✓ Fixed
Host Setting Saves Correctly
Printer host addresses, API keys, and connection settings persist between sessions. The private qidi_networking.dll is no longer required.
Missing DLL caused Host Setting to silently discard every save.
✓ Fixed
Clean Installer
The Windows installer builds and runs without error. No more 0xc000007b crashes on launch for users with non-standard Windows configurations.
The official QIDIStudio_Setup_*.exe regularly ships as a corrupt executable (exit code 0xc000007b).
✓ Fixed
Filament Preset Resolution
Custom filament presets correctly resolve temperature, flow, and pressure advance values. No silent fallback to wrong profiles when filament_settings_id points to a user-created entry.
Temperature lookups fell back to wrong profiles silently.
✓ Fixed
Production Cloud by Default
First-run defaults to the production cloud environment. No more connecting new users to a staging server that returns empty printer lists and confusing errors.
iot_environment = "2" (staging) was hardcoded as the default.
↑ Improved
Materials Database Sync
Cloud-synced material profiles via the NexusSlicer materials API. Hundreds of community-tuned filament profiles — temperature, flow, pressure advance — updated automatically.
